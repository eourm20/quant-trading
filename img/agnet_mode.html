Agent Mode 코드 흐름도

코드 함수 단위 호출 경로 + Agent별 Preflight/도구/실행 게이트를 그래프 형태로 정리

1) 전체 오케스트레이션 그래프

요약: 스케줄러가 판단/리서치/정책 루프를 돌리고, 중간 게이트를 통과한 경우에만 실제 실행됩니다.

핵심 파일: worker/main.py, worker/claude_judge.py, worker/agents/*.py, worker/strategy_reflection.py

실행 함수 게이트/검증 DB/기록 Agent Tool Loop

2) JudgmentAgent 그래프

요약: 실시간 신호를 즉시 판단하되, 필수 컨텍스트가 비면 INCOMPLETE_CONTEXT로 중단합니다.

JUDGMENT 실시간 신호 판단 (매수/매도/홀드)

3) ResearchAgent 그래프

요약: 후보를 찾고 검증한 뒤 정책 게이트를 통과한 종목만 watchlist에 등록합니다.

RESEARCH 장마감 후보 발굴 + watchlist 등록

4) 도구 역할 맵 (보기 쉽게 압축)

요약: 같은 도구라도 Judgment는 "지금 행동" 중심, Research는 "후보 검증" 중심으로 사용합니다.

영역 핵심 도구 Judgment에서 쓰는 이유 Research에서 쓰는 이유
시세/차트 get_current_price, get_chart, get_market_index 지금 신호가 진짜 유효한지 확인 후보가 이미 과열/붕괴인지 1차 필터링
컨텍스트 position_context_brief, get_signal_history, get_trade_performance 왜 들어갔고 이전 판단이 맞았는지 반영 과거 추천 품질/유형 성과 반영
뉴스/거시 market_news_brief, get_news, rss_macro_brief, get_dart 종목/시장/정책 이벤트 반영 테마/실적/리스크 검증
스캔 scan_volume_surge, scan_foreign_buy, scan_decline_rank 보조(필요시만) 후보 발굴의 시작점
RAG/메모리 search_agent_memory_context, search_text_context, search_screening_context 유사 상황 재확인 유사 케이스/과거 실패 패턴 회피
실행 execute_order, add_to_watchlist AUTO 모드에서만 주문 실행 policy_gate 통과 시만 등록

5) Reflection -> Policy 루프 그래프

요약: 실행 결과를 복기 로그로 쌓고, 안전장치를 통과한 low-risk 정책만 자동 반영합니다.

SYSTEM LOOP low-risk만 자동 반영, 위험/충돌은 큐 보류
