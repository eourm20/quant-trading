핵심 흐름을 쉽게 보고, 필요하면 전체 도구 목록 탭에서 상세 확인

기능 A) 실시간 판단 흐름 (JudgmentAgent)

1신호 감지: run_check()
2판단 호출: get_trade_opinion() -> JudgmentAgent.run()
3사전 점검: 보유이유/이전판단/뉴스/시장/거시/성과 확인
4누락 검사: 부족하면 INCOMPLETE_CONTEXT로 종료
5실행 게이트: 중단 상태면 주문 차단

중요: INCOMPLETE_CONTEXT면 주문 실행 안 함

기능 B) 장마감 발굴 흐름 (ResearchAgent)

1시작: run_daily_screening()
2리서치 호출: ResearchAgent.run()
3사전 점검: 시장/거시/중복보유/공시/과거추천성과 확인
4스캔 + 검증: 거래량/수급/뉴스/공시
5등록 게이트: 통과 종목만 add_to_watchlist

기능 C) 모니터링 자동 실행 흐름 (Scheduler)

장중에는 스케줄러가 반복적으로 조건을 확인하고, 쿨다운/중복방지 규칙을 거친 뒤 필요한 경우만 AI 판단과 실행으로 연결합니다.

1정기 실행: 스케줄러가 장중 작업을 주기적으로 실행
2신호 선별: 의미 있는 신호만 다음 단계로 전달
3리스크 필터: 쿨다운/중복주문/금지조건 차단
4실행 완료: 판단/주문/로그가 한 사이클로 저장

기능 D) 복기 기록과 정책 반영 흐름

D는 '기록/반영' 단계입니다. 실행 직후 복기 로그는 즉시 저장되고, 정책 변경은 평일 16:20 루프에서만 반영됩니다.

기능 E) 에이전트 행동 변화 흐름 (다음 실행 반영)

E는 '적용/체감' 단계입니다. 모델 재훈련이 아니라, 갱신된 정책과 컨텍스트가 다음 판단 행동을 바꿉니다.

3실행강도 조절: 진입 허용, 수량 배수, 추천 개수 등 행동 강도 조절
4결과 재측정: 다음 주기 성과로 다시 복기되어 D 단계로 환류
5핵심 타이밍: 즉시 저장(실행 직후) / 정책 반영(평일 16:20) / 행동 변화(다음 실행)

복기 기반 학습이 반영되는 순간
