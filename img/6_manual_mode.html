수동 모드 프로세스 가이드

Claude Desktop (MCP 연동)을 통해 대화형으로 포트폴리오 관리, 매매 실행, 전략 수립을 합니다

⚡ 수동 모드 vs 자동 모드

두 모드는 독립 실행 가능하며, 같은 DB를 공유합니다. 동시 실행도 가능.

수동 (Claude Desktop + MCP)자동 (백그라운드 워커)
종목 추천추천만 → 사용자가 판단추천 + watchlist 자동 추가
초기 임계치자동 제안 → 사용자 확인 후 등록AI가 자동 설정
신호 → 행동텔레그램 알림 → 사용자 승인AI 판단 → 자동 매매
포트폴리오 동기화MCP auto_sync (10분)워커 스케줄러 (2분)
프로세스 가이드이 페이지자동 모드 가이드 →

💹 매매 실행 프로세스 (상황 2)

사용자: "삼성전자 100주 매수해줘"

키움 MCP: 주문 실행 kiwoom_execute_api 호출 → 주문번호 수신
쿨다운 리셋quant_cooldown_reset

📋 매매 후 자동 처리 (3단계)

순서도구이유
1 quant_cooldown_reset(stock_code) 새 포지션 기준으로 신호가 다시 와야 하므로 이전 쿨다운 제거
2 quant_strategy_log(category="trade") 매매 근거 기록 + 텔레그램 발송
3 quant_portfolio_sync() 포트폴리오 DB를 키움 실제 잔고와 동기화
주의: 실제 주문에는 KIWOOM_ALLOW_TRADE_EXECUTION=true 설정이 필요합니다. false일 때 주문 시도 시 에러가 발생합니다.
